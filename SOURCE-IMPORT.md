# OmniDev Swarm source import

This repository contains the complete tracked source snapshot of OmniDev Swarm Sites version 45 (commit `439c6c1a275ba01ad346e4e11890e58f024c6efc`).

Included: application, local account engine/installer/updater, execution worker, tests, migrations, assets, architecture documents, Build Bible and PDF deliverables, completion audit, unfinished-work records, and redistributable vendor files.

See `evidence/github-source-import.json` for the SHA-256 inventory of every imported source file. Generated compiler caches, installed packages, local runtime databases, user credentials and account sessions are excluded. Downloadable signed engine packages contain source and public verification material, not the private release signing key.

This is a source transfer, not a claim that production work is complete. Open `UNFINISHED-WORK/README.md` and `COMPLETION-AUDIT/` for outstanding work. Application-container qualification, provider access, and live deployment configuration must be independently verified. Existing Sites publication has not been moved or disconnected by this import.
