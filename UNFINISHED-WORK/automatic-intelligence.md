Account token refresh is protected by a cross-process single-flight lock. Existing engine batches finish before update activation; never interrupt active model calls to install this release.
Verified with real loopback fixture inference: four simultaneous requests and exact ceiling; pause/resume; no duplicate completed calls; settings readable while busy; fair dispatch; single-flight refresh.
